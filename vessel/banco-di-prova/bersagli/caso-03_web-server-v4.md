## Storia visiva / set
Linea di confezionamento all'alba, macchina ferma (mondo IBRIDO). Firma: il «diario luminoso» — ogni evento stampa dentro la CPU una riga
con l'orario; le righe escono dal quadro chiuso e si dispongono in aria in ordine di ora attorno a lui. Il tecnico apre un portatile sul
carrello e la colonna di eventi sale dallo schermo, col quadro che resta chiuso; la pila precipita e la barra rossa (il primo evento) sta
in fondo.
